PAGER

Privacy

The short version

PAGER does not store, collect, or transmit any of your data to any server we control. Everything stays in your browser.

Your GitHub token

When you sign in, your GitHub personal access token (or the OAuth token obtained via GitHub login) is stored in your browser's localStorage on your device only.

It is sent directly to api.github.com when you read or write files. It never passes through any PAGER server.

Your content

Posts, pages, and media you create or edit are read from and written directly to your GitHub repository via the GitHub API. PAGER has no database, no file storage, and no backend that touches your content.

OAuth (GitHub login)

If you use the "Login with GitHub" option, your browser is redirected to GitHub to authorise the app. GitHub then provides an authorisation code, which is exchanged for an access token via a small serverless worker. That worker performs the exchange and returns the token to your browser - it does not log, store, or retain anything.

Cookies and tracking

PAGER uses no cookies, no analytics, no tracking pixels, and no third-party scripts.

If you want to remove PAGER's access to your GitHub account entirely, revoke the token from Installed Github Apps.
